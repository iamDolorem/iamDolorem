## Избранные проекты

### [Digital Products Marketplace](https://github.com/iamDolorem/pixio-digital-marketplace)

Дипломный проект: web-приложение для продажи цифровых продуктов с ролями покупателя и продавца, каталогом, корзиной, заказами и серверной частью.

В проекте реализованы клиент-серверная архитектура, REST API, работа с PostgreSQL, авторизация пользователей, разграничение ролей и базовая бизнес-логика marketplace.

**Стек:** C++, Drogon, PostgreSQL, Astro, Svelte, Tailwind CSS.
### [Student Progress Automation Bot](https://github.com/iamDolorem/student-progress-automation)

Python-бот для автоматизации работы куратора онлайн-курсов.

Проект решает реальные рутинные задачи: отслеживает новые домашние задания, отправляет уведомления в Telegram, подбирает шаблоны ответов, формирует еженедельные отчёты и обновляет Excel-таблицу прогресса после подтверждения.

В проекте реализованы безопасный сценарий preview / confirm, работа с Telegram Bot API, автоматизация браузера через Playwright и обработка Excel-файлов.

**Стек:** Python, Playwright, Telegram Bot API, openpyxl, requests, python-dotenv.

### [DDS Service](https://github.com/iamDolorem/dds-service)

Django web-сервис для учёта движения денежных средств.

В проекте реализованы CRUD-операции, фильтрация записей, управление справочниками, зависимые категории и подкатегории, серверная валидация, отображение итогов и REST API для динамического обновления форм.

**Стек:** Python, Django, Django ORM, Django REST Framework, django-filter, SQLite, Bootstrap, JavaScript.

### [Containerization & Orchestration](https://github.com/paniniLi/Semester_1-containerization_and_orchestration)

Командный учебный проект по контейнеризации, оркестрации и эксплуатации приложений в Kubernetes.

Реализованы развёртывание сервисов, настройка сетевого взаимодействия, мониторинг и алертинг, управление трафиком и автоматизация релизов.

**Стек:** Docker, Kubernetes, Helm, Cilium, Prometheus, Grafana, Git.

### [Industrial Backend Go](https://github.com/iamDolorem/industry_backend_go_autumn_2026)

Учебный проект по backend-разработке на Go в рамках магистратуры ИТМО.

Реализованы задачи по работе со структурами данных, конкурентному программированию, потокобезопасности, HTTP API и обработке ошибок.

**Стек:** Go, HTTP, REST API, goroutines, channels, sync, Git.

### [Effective Mobile test](https://github.com/iamDolorem/effective-mobile-test)

Мини-проект с Python backend, nginx и Docker Compose. Backend доступен внутри docker-сети, наружу опубликован только nginx.
